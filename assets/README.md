# Logo assets

SVG and 512 × 512 transparent PNG artwork from the libtmux logo kit,
revision `555f60aff5341d8ba59c7466eb9abb537084c98d`.

Library marks use the cog. Language colors follow
[GitHub Linguist](https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml).
The source libtmux artwork belongs to the project owner.

Package-specific artwork sits beside its README where the package format
supports it: `lua/libtmux/assets`. The README check requires each README to
open with the centered logo block and rejects art that differs between the
READMEs of one product.
`.github/social-preview.png` is the cog sharing card, ready to upload under the
repository's **Settings → Social preview**.

The sharing card comes from `assets/lua/library/opengraph-light.png`
at kit revision `4b86a9d9158d7c6d52cd635d59c92a04b48b960f`.
